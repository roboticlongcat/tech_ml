# Технологии машинного обучения

## О репозитории

Лабораторный практикум по курсу «Технологии машинного обучения» (6 семестр, кафедра ИУ5, МГТУ им. Н.Э. Баумана). В репозитории собраны лабораторные работы, охватывающие полный цикл ML: от предобработки данных и визуализации до ансамблевых методов, нейронных сетей, прогнозирования временных рядов и снижения размерности.

## Содержание

**Предобработка и валидация**
- Обработка пропусков, кодирование категориальных признаков, масштабирование
- Подготовка обучающей и тестовой выборок
- Кросс-валидация и подбор гиперпараметров (на примере KNN)

**Классические алгоритмы**
- Линейные модели, SVM, деревья решений

**Ансамблевые методы**
- Бэггинг, случайный лес, сверхслучайные деревья
- AdaBoost
- Градиентный бустинг
- Стекинг
- Методы оптимизации

**Нейронные сети**
- Многослойный персептрон (MLP)

**Прогнозирование временных рядов**
- Авторегрессионные методы (ARMA, ARIMA)
- Символьная регрессия
- МГУА (методы COMBI/MULTI и MIA/RIA, библиотека `gmdh`)

**Снижение размерности**
- Метод главных компонент (PCA) — снижение до 2 компонент (датасет D2)
- Алгоритм t-SNE — снижение до 2 компонент (датасет D3)

## Стек

- **Язык:** Python
- **ML:** Scikit-learn, gmdh
- **Данные:** Pandas, NumPy
- **Визуализация:** Matplotlib, Seaborn
- **Среда:** Jupyter Notebook
- **Дополнительно:** TensorFlow / PyTorch
